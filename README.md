# 🧭 3D 迷宫 · 困难模式

这是一个基于 **Three.js** 构建的沉浸式 3D 迷宫探险游戏。玩家需在第一人称视角下，通过键盘与鼠标操作，在随机生成的迷宫中寻找金色出口。项目支持动态难度切换，并针对移动端和桌面端进行了适配。

![3D迷宫游戏预览](https://via.placeholder.com/800x400?text=3D+Maze+Preview)

---

## 🎮 项目概述

- **核心玩法**：在由程序生成的 3D 迷宫中，找到发光的金色出口以获胜。
- **难度选择**：提供 **简单 (11x11)**、**困难 (21x21)**、**大师 (31x31)** 三种地图尺寸，影响迷宫复杂度和路径长度。
- **交互方式**：
    - **移动**：键盘 `W/A/S/D` 控制前后左右移动。
    - **视角**：鼠标拖动旋转视角（需点击画面锁定鼠标）。
    - **加速**：按住 `Shift` 键可提高移动速度。
- **视觉反馈**：动态的出口光柱、粒子特效和闪烁光环，获胜时显示庆祝弹窗。

---

## 🛠️ 技术实现

### 核心技术栈
- **3D 引擎**：Three.js (r128) – 负责场景渲染、光照、阴影与相机控制。
- **迷宫生成算法**：递归回溯法（Recursive Backtracking），并额外随机打通 3% 的墙壁以增加死路和复杂度。
- **碰撞检测**：基于玩家包围盒（0.3 半径）与网格地图的精确检测，防止穿墙。

### 代码架构
```plaintext
1. 迷宫生成
   - generateMaze(size) → 返回二维网格、起点、终点
   - 递归回溯 + 额外随机开口

2. 场景构建
   - 墙壁、地板、天花板 (Three.js Mesh)
   - 动态出口标记：光柱、旋转光环、粒子系统
   - 起点光晕 (PointLight)

3. 玩家控制
   - PointerLockControls 风格的鼠标视角
   - 键盘状态监听 (keydown/keyup)
   - 基于四元数的平滑移动

4. 游戏循环
   - 每帧更新玩家位置 → 碰撞检测 → 胜利判定
   - 出口动画 (旋转光环、呼吸光效)
